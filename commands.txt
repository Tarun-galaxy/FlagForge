========================================================================
                      FLAGFORGE RUN COMMANDS REFERENCE
========================================================================

Follow the instructions below to configure, launch, and test the FlagForge application locally.

------------------------------------------------------------------------
0. PREREQUISITES
------------------------------------------------------------------------
Make sure you have the following tools installed on your host machine:
* Python (Version 3.10 or higher)
* Node.js (Version 18 or higher)
* Docker & Docker Compose (for running PostgreSQL and Redis)

------------------------------------------------------------------------
1. SERVICES DEPENDENCIES (PostgreSQL & Redis)
------------------------------------------------------------------------
To launch the background database and cache containers, run this command
from the project root directory:

  docker-compose up -d

This spins up:
* PostgreSQL (Access URL: postgresql://postgres:postgres@localhost:5432/feature_flags)
* Redis (Access URL: redis://localhost:6379/0)
* LibreTranslate (Access URL: http://localhost:5000)

------------------------------------------------------------------------
2. BACKEND API SERVER (FastAPI)
------------------------------------------------------------------------
To initialize and launch the backend Python API, run these commands:

  # 1. Navigate to backend directory
  cd backend

  # 2. Create Python virtual environment
  python -m venv venv

  # 3. Activate the virtual environment
  # On Windows PowerShell:
  .\venv\Scripts\Activate.ps1
  # On Windows Command Prompt:
  .\venv\Scripts\activate.bat
  # On macOS/Linux:
  source venv/bin/activate

  # 4. Install dependency packages
  pip install -r requirements.txt

  # 5. Run database migrations to construct schemas
  alembic upgrade head

  # 6. Start the FastAPI ASGI server
  python -m uvicorn app.main:app --port 8000

The Backend Swagger API documentation is available at:
* http://localhost:8000/docs
* http://localhost:8000/redoc

------------------------------------------------------------------------
3. FRONTEND DASHBOARD (React + Vite)
------------------------------------------------------------------------
To initialize and launch the frontend React Dev server, run these commands:

  # 1. Navigate to frontend directory
  cd frontend

  # 2. Install Node package dependencies
  npm install

  # 3. Launch Vite Dev server
  npm run dev

The Frontend Web Dashboard interface is available at:
* http://localhost:5173
